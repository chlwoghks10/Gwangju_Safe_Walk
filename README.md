# 주제 : 광주 안심길

공공데이터 기반 광주 보행 경로 비교 안내 앱

**팀 익셉션** · 조선대학교 정보통신공학과 캡스톤디자인

---

## 만드는 이유

밤에 혼자 걸을 때 어느 길이 나은지 알 방법이 없습니다.
지도 앱은 최단 경로만 알려주고, 안심시설을 반영한 경로 안내는 서울등 다른 지자체에만 있습니다.

이 앱은 **최단 경로와 안전 우선 경로를 나란히 제시하고, 각 경로에 어떤 시설이 있는지 지도와 수치로 보여줍니다.**

### 설계 원칙

> **안전을 판정하지 않습니다. 판단할 근거를 제시합니다.**

어느 길이 안전한지는 증명할 수 없습니다. 사고가 일어나지 않았다는 것은 측정되지 않기 때문입니다.
대신 **"이 경로에 CCTV와 보안등이 몇 곳 있다"는 사실은 현장에서 확인할 수 있습니다.**
시스템은 경로를 대신 고르지 않고, 두 경로의 정보를 제시하고 선택은 사용자가 합니다.

## 배경

| 지표 | 값 | 출처 |
|---|---|---|
| 밤에 혼자 걸을 때 불안 | 30.5% | 통계청 2024 사회조사 |
| 여성 | 44.9% (남성 15.8%) | 〃 |
| 불안 이유 중 인적 드묾 | 26.4% | 〃 |
| 불안 이유 중 안전시설 부족 | 16.9% | 〃 |

불안 요인의 **43.3%가 물리적 보행 환경**에서 비롯됩니다. 이 프로젝트가 다루는 영역입니다.

광주에는 여성안심귀갓길 55개 구간이 지정돼 있으나 고정 구간이며,
출발지와 도착지에 맞춰 경로를 안내하는 서비스는 확인되지 않았습니다.

### 1. 공공데이터 수집 및 정제

| 데이터 | 원본 | 정제 후 |
|---|---|---|
| CCTV | 6,805행 | **6,802지점** |
| 보안등 | 33,548행 | **18,745지점 / 22,893개** |
| 안전비상벨 | — | **158지점** |
| 경찰서·지구대 | — | **40지점** |

- 동일 좌표에 연도별 중복 등록된 증설 기록을 지점 단위로 통합, 대수 합산
- 좌표 결측 및 행정구역 범위 이탈 값 제거
- 지도 레이어는 GeoJSON 으로 형식 통일

### 2. 보행 도로망 구축 및 구간별 시설 집계

- OSMnx로 조선대 반경 1km 보행 전용 도로망 확보 — **노드 1,616 / 간선 4,211 / 총 연장 102km**
- 구간 꺾은선을 따라 점–선분 최단거리로 반경 내 시설 집계
- 매칭 반경 30m → 50m 상향 후 CCTV 미보유 구간 79% → **69%**, 보안등 57% → **48%**
- 

### 3. 경로 API 서버 (AWS EC2)

경로 계산은 서버에서 수행하고, 앱은 좌표를 보내고 결과를 받아 그립니다.

```
  안드로이드 앱                 AWS EC2 서버
 ┌──────────────┐  좌표 전송   ┌──────────────────────┐
 │ 지도에서 출발·│ ──────────> │ FastAPI              │
 │ 도착지 선택   │             │  ├ 다익스트라 2회     │
 │              │  두 경로 +   │  │  (거리 / 안전비용) │
 │ 경로 2개 +   │ <────────── │  └ 경로 주변 시설 조회│
 │ 시설 마커 표시│   시설 좌표  │    (반경 50m, 격자색인)│
 └──────────────┘             └──────────────────────┘
```

- 서버 기동 시 도로망과 시설을 1회 적재, 요청마다 재계산하지 않음
- 
### 6. 안드로이드 앱

- 스플래시 → 대시보드 → 안심지도 / 안심경로 / 메뉴 화면 구성
- 네이버 지도 SDK 연동
- **정제 데이터 25,745지점을 지도에 표시** (화면 범위 기준 렌더링, 줌 단계별 레이어 표시)
- CCTV·보안등·비상벨·경찰서 레이어 개별 토글
- 지도 탭으로 출발·도착 지정 → 서버 호출 → **두 경로와 경로에 쓰인 시설을 함께 표시**
- EC2 재시작 시 주소가 바뀌므로 앱 내에서 서버 주소 변경 가능(추후 탄력적 ip 사용 계획)

## 실행 방법

### APK 설치

[Releases](../../releases)에서 `app-debug.apk`를 내려받아 설치합니다.
설치 시 "출처를 알 수 없는 앱" 경고가 표시되면 허용해 주세요.

**경로 비교는 서버가 실행 중이어야 동작합니다.**
경로 화면 우측 상단 `서버` 버튼에서 현재 EC2 퍼블릭 IP 를 입력하세요.
안심 지도(시설 분포)는 서버 없이 동작합니다.

### 서버 실행

```
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

확인: `http://<주소>:8000/docs`

### 소스 빌드

```
Android Studio에서 프로젝트를 열고 Gradle Sync 후 실행
```

지도 표시에는 네이버 클라우드 플랫폼 Application 키가 필요합니다.
`AndroidManifest.xml`의 `NCP_KEY_ID` 값을 본인 키로 교체하고,
콘솔에 Android 패키지명 `com.exception.gwangju_safe_walk`를 등록해야 합니다.

## 확인된 한계

데이터를 직접 검증하며 확인한 제약을 기록합니다.

**보안등 데이터 범위 불일치** — CCTV·비상벨·경찰서는 5개 구, 보안등은 동구·북구·서구 3개 구입니다.
광산구는 보안등 10,439행 전체의 좌표가 미기재되어 있고,
남구는 28행의 동 단위 집계(예: 월산동 1,436개가 단일 좌표)로 지점 단위 분석이 불가능했습니다.
조선대(동구)와 전남대(북구)가 모두 포함되어 연구 목적에는 영향이 없습니다.

**도로망 범위** — 광주 주변으로 한정되어 있어 그 밖의 좌표는 요청이 거부됩니다.
